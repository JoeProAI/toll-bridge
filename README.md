# Toll Bridge

A PayPal-backed tab for AI agents. You approve one budget hold in PayPal. Your agent pays per tool call out of that hold, and PayPal only captures a call's toll when the result passes its checks. A failed call costs nothing, and whatever's left on the hold is voided when the tab closes.

Built for the PayPal AI Hackathon 2026 (PayPal sandbox only).

Status: under construction. `prototype/python/` is the first clean-room prototype (mocked PayPal, heuristic model). The production build is in progress.
