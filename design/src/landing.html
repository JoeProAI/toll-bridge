A PayPal tab for AI agents

Give your agent a tab, not your card.

Approve one PayPal hold. Your agent pays per answer out of it, and PayPal captures a toll only when the answer passes its quote check. Writers whose pages were quoted get paid through PayPal Payouts. The rest of the hold is voided when the tab closes.

Sandbox demo. Holds and captures are real PayPal sandbox calls.

Three PayPal calls. You only pay for checked work.

  1. Toll 01Hold

    Hold

    You approve one budget in PayPal. It’s an authorization, so the money is held, not spent.

    Orders v2, intent: AUTHORIZE
  2. Toll 02Earn

    Earn

    Each answer gets a quote, runs, then faces the quote check: schema, exact source quotes, coverage, and a judge. Pass, and PayPal captures that one toll. Fail, and nothing moves.

    capture, final_capture: false
  3. Toll 03Void

    Void

    Close the tab and the rest of the hold goes back. Every cent captured has a receipt with its PayPal ID.

    authorizations/{id}/void

For writers

Quoted? You get paid.

Toll Bridge reads each page’s RSL license before an agent may use it. If the license names a per-use price and a PayPal payee, a verified quote sends that royalty through PayPal Payouts. If it says no AI use, the page is refused at $0.00.

For agents

Plain HTTP

Ask, get a 402 with a quote, pay with the quote.

curl -X POST $HOST/api/tools/wring \
  -H "authorization: Bearer $TAB" \
  -d '{"input":"https://example.com/long-page"}'
# 402 { quote: { price: "0.50" }, quote_token }

curl -X POST $HOST/api/tools/wring \
  -H "authorization: Bearer $TAB" \
  -H "x-toll-quote: $QUOTE" \
  -d '{"input":"https://example.com/long-page"}'
# 200 { call: { verdict, capture_id }, result }
